# BiliBiliSubtitle

Chrome Manifest V3 插件，为 B 站视频提前生成字幕：**下载完整音轨 → 识别 → 显示原文**。需要译文时再开启翻译。无需构建、本地服务器或 FFmpeg。

## 1.3 新功能

- **字幕背景透明度（1.3.1）**：播放器「AI 字幕 → ⋯」拖动滑块立即预览、松开自动保存，切 P 和刷新后保留；100% 去掉底色，文字保持清晰。设置页「字幕样式」也可调整并保存。
- **识别档位**：默认「原音轨整段直传（推荐速度）」。失败自动切换分段识别，再失败切换兼容识别。无需设置切片时长、并发数或批量上限。
- **自由选择**：在分 P 和合集目录中搜索、复选、全选搜索结果或清空。选择会在本次浏览器会话中保留；单次最多 500 个视频。
- **跟随识别下一 P**：播放当前视频时，在后台准备紧接着的下一 P；不递归处理整个合集。
- **全自动识别**：进入视频页后自动生成字幕，切 P 后继续跟随。自动任务遇到可用原生字幕直接跳过，不调用识别或翻译服务。
- **独立翻译开关**：手动任务和自动任务都遵守它。默认关闭，原文识别完成即可播放或导出，不受翻译等待和失败影响。
- **模型选择**：识别和翻译分别提供下拉列表及「刷新模型」，也可手动填写自定义模型 ID。
- **注册入口**：密钥栏下方提供[硅基流动注册 / 获取密钥](https://cloud.siliconflow.cn/i/cW7ksWMh)，使用作者提供的邀请链接。

全自动和下一 P 跟随开关默认关闭，在弹窗及设置页均可操作并同步。弹窗修改立即生效；设置页修改后点击「保存设置」。关闭自动开关会停止对应的自动任务，手动任务继续执行。

## 使用

生成范围可选「当前视频」「全部分 P」「整个合集」或「自由选择」。自由选择只处理勾选的视频；默认复用已识别原文和字幕缓存，勾选「忽略缓存」才会重新识别。用户示例 [BV13Q4y1C7hS](https://www.bilibili.com/video/BV13Q4y1C7hS/) 是 200 个分 P，可直接全选或只选需要的章节。

生成时无需播放，可以关闭弹窗，但需保持浏览器运行。任务逐个视频处理，单集失败不影响后续视频。自动任务等待当前手动任务完成后执行；自动预识别始终只跟随下一集。取消任务会清空等待中的自动队列。关闭浏览器或重载扩展会中断当前任务，已完成字幕与识别片段会保留。

播放器中的 AI 字幕按钮可开关字幕、调整延迟、字号和背景透明度。透明度适用于所有视频，默认 24%（保持原有底色），不会重新识别或翻译。支持进度跳转、倍速、网页全屏和播放器全屏。独立画中画窗口不包含此字幕层。弹窗可导出 SRT / VTT。

## 模型与接口

| 用途 | 预置 / 默认 |
| --- | --- |
| 识别服务 | 硅基流动，`https://api.siliconflow.cn/v1` |
| 识别模型 | `FunAudioLLM/SenseVoiceSmall`（默认）、`TeleAI/TeleSpeechASR` |
| 翻译模型 | DeepSeek-V4-Flash、DeepSeek-V4、GLM-5.2、Kimi-K2.7-Code，以及原有 Qwen2.5-7B-Instruct |
| 翻译默认 | 原有 `Qwen/Qwen2.5-7B-Instruct`，目标语言简体中文 |

2026-09-07 官方转写接口明确列出的识别模型是上述两个。语音合成模型不能用来识别字幕。点击「刷新模型」后，硅基流动通过 `/models?sub_type=speech-to-text` 或 `/models?sub_type=chat` 分别获取账户可用模型；模型上下线、权限和价格以账户返回和控制台为准。

翻译 Key 留空且两个接口地址同源时，复用识别 Key；不同域名需分别填写。自定义兼容接口使用 `/audio/transcriptions` 和 `/chat/completions`。API 地址填基础地址，不包含完整接口路径。保存设置或刷新模型时会申请对应域名的访问权限。密钥不会出现在视频页面、字幕文件和任务记录中。

## 识别方式

| 档位 | 实际处理 |
| --- | --- |
| 原音轨整段直传（默认） | 直接上传原始压缩音轨；超出单次限制或失败时自动换下一种方式 |
| 分段识别（更稳） | 默认按约 120 秒分段，保留 AAC 原始音频；失败后自动换兼容方式 |
| 兼容识别（较慢） | 本机解码，默认按约 25 秒转换为 WAV 上传 |

自动切换复用同一次下载的音轨，已成功片段会保存。Key 无效、欠费、无权限、模型不存在或限流不通过换格式解决，因此直接报告错误；取消不会触发下一次上传。超时、格式不兼容等识别失败会自动尝试后续方式。已提交的请求如何计费取决于服务商。

硅基流动单请求文档限制为 50 MB / 1 小时，插件按 49 MB 保守阈值判断整段上传。兼容接口按 24 MB 处理。单个视频最长 180 分钟、音轨最大 300 MB；长音轨自动分段。设置页保存后使用统一处理参数，识别请求最多等待 180 秒，翻译每批最多 180 秒。旧版已保存的超时值在重新保存前仍有效。

**SenseVoiceSmall / TeleSpeechASR 官方接口仅承诺返回文本，不返回逐句时间戳。** 整段识别的字幕时间为粗略估算，可能与说话不同步；分段只能细化估算。准确时间轴需要视频原生字幕或返回 `segments: [{start,end,text}]` 的识别接口，换成另一个仅返回文本的模型不会自动解决对齐问题。

插件优先下载最低码率独立音轨，下载失败时切换 B 站返回的备用 CDN。不下载视频画面，也不读取 Chrome 磁盘视频缓存。暂不支持直播、番剧、受保护音轨及没有独立 DASH 音轨的视频。

## 常见问题

- **401 / 403**：检查 Key、服务地址与账户模型权限。
- **429**：检查余额或配额，等待后重试。
- **B 站风控 / 下载失败**：登录 B 站，确认视频可播放，等待后重试。
- **翻译失败**：可先使用原文；重试复用已完成识别，不重复上传音轨。
- **模型不在预置列表**：刷新账户模型，或选「自定义模型」填写 ID。
- **自动任务失败后不再重试**：同一会话内避免反复提交；可手动生成，或关闭再开启自动开关。
- **字幕重叠**：在播放器里关闭 B 站原生字幕或插件字幕中的一层。

## 开发与验证

```powershell
npm test
npm run check
npm run package
```

输出 `dist/bili-whole-subtitles.zip`。运行时依赖的 MP4Box.js 已随包提供，许可见 `src/vendor/LICENSE`。

### 自动发布 Release

将 `manifest.json` 和 `package.json` 的版本号同步更新并提交，然后推送对应标签。例如版本号为 `1.3.1` 时：

```powershell
git push origin main
git tag v1.3.1
git push origin v1.3.1
```

GitHub Actions 自动检查代码、运行测试、生成 `dist/bili-whole-subtitles.zip`，校验标签和安装包版本一致后发布 Release，附带 ZIP 和 SHA-256 校验文件。失败时不会新发布 Release。也可在 Actions 的「Build and release extension」中手动运行，填写已有的版本标签重试。无需配置额外密钥。

`scripts/browser-smoke.mjs` 在隔离浏览器目录中以模拟接口验证：识别、翻译、缓存、自动触发、下一 P、200P 多选、导出、取消、模型刷新及格式回退。通过 `BILI_PLAYWRIGHT_PATH` / `BILI_BROWSER_PATH` 配置测试运行时；`BILI_TEST_AUDIO` 可指向实际 M4A 测试素材。没有使用用户真实 Key 或进行付费请求。

实际用户视频的 704 秒 / 5.65 MiB M4A 音轨已用于本机下载、无损分段与浏览器解码验证。模型识别质量、真实云端耗时和计费需要使用自己的账户确认。详细记录见 [VALIDATION.md](VALIDATION.md) 与 [RESEARCH.md](RESEARCH.md)。

官方参考：[转写接口](https://docs.siliconflow.cn/docs/api/audio-transcriptions-post)、[模型列表](https://docs.siliconflow.cn/docs/api/models-get)、[对话接口](https://docs.siliconflow.cn/docs/api/chat-completions-post)。
